Course thumbnails can use any filename. Set the matching filename on the
course's `thumbnail` field in `src/data/courses.ts`.

Courses without a `thumbnail` field can also use numbered files:
  1.jpg, 2.jpg, 3.jpg ... 27.jpg

.jpg, .png, .webp and .jpeg all work. Recommended size: 1280 x 720 (16:9).
Until a file exists, the site shows a purple placeholder for that course.
